# 05 建檔作業流程

| 項目 | 內容 |
|---|---|
| 對象 | 建檔人員 |
| 文件版本 | v1.0 |

## 1. 流程總覽

```text
1 依書櫃分批 → 2 拍攝目錄頁 → 3 AI 擷取 → 4 人工校對
→ 5 貼進目錄 → 6 資料檢查 → 7 貼標籤、上架
```

每批處理一層書櫃。整批完成、檢查通過後再進行下一批，避免錯誤累積。

## 2. 拍攝目錄頁

| 情況 | 拍攝方式 |
|---|---|
| 有目錄頁的曲集 | 拍所有目錄頁 |
| 沒有目錄頁的曲集 | 逐頁拍下每首曲子的第一頁；或直接手動輸入 |
| 單張樂譜 | 拍第一頁 |
| PDF 教材 | 直接使用 PDF 的目錄頁，不需拍照 |

**拍攝要點**
- 光線充足，避免反光與陰影。
- 頁面拍滿畫面，文字清晰、不歪斜。
- 支援 JPG、PNG、WEBP 與 PDF。

**檔案整理方式**

```text
input/toc_photos/
    B0001_布爾格繆勒25首.jpg        一張照片 = 一本書
    B0003_克萊曼蒂小奏鳴曲/          一個資料夾 = 一本書
        01.jpg                      多頁依檔名順序處理
        02.jpg
```

檔名或資料夾名稱會記錄在擷取結果的備註欄，校對時方便對照實體書。

## 3. AI 擷取（大量建檔）

### 3.1 準備（只需做一次）

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r tools/requirements.txt
```

設定 Claude API 金鑰：寫在專案根目錄的 `.env`，見《08 API 與金鑰設定》第 2 節。

### 3.2 執行

先從目錄匯出目前的書籍表與曲目表 CSV，讓新編號接在現有編號之後：

```bash
python tools/extract_toc.py input/toc_photos \
    --catalog-books 書籍.csv --catalog-pieces 曲目.csv --out output/
```

產出兩個檔案：

| 檔案 | 內容 |
|---|---|
| `output/擷取_書籍.csv` | 每本書一列；類型、位置留白，由校對人員填寫 |
| `output/擷取_曲目.csv` | 每首曲目一列；備註標示「AI 擷取，待校對」或「AI 不確定，請特別確認」 |

某本書擷取失敗時，程式會繼續處理其他書，最後列出需要重做的清單。

### 3.3 費用

每本書呼叫一次 Claude API，費用依頁數而定。試點時記錄 20 本的實際費用，再推估全部建檔的總費用，並列入報價。

## 4. AI 擷取（少量新增）

教室日常新增一兩本書時，不需要執行程式，直接使用 Claude 或其他 AI 對話工具即可：

1. 上傳目錄頁照片。
2. 貼上以下指示：

```text
這是一本鋼琴曲集的目錄頁。請依印刷順序列出每一首曲子，
輸出成表格，欄位為：曲名、作曲家、頁碼。
曲名保留原文與作品編號；看不清楚的地方請標註「不確定」，不要猜測。
```

3. 將結果對照書本校對後，貼到曲目表。

## 5. 人工校對（必做）

每一筆都要對照實體書確認。AI 最常出錯的地方：

| 常見錯誤 | 檢查方式 |
|---|---|
| 外文曲名拼錯，例如變音符號遺漏 | 逐字對照 |
| 頁碼錯一位數 | 翻到該頁確認 |
| 把章節標題當成曲目 | 刪除非曲目的列 |
| 作曲家空白 | 依封面或曲目頁補上 |

校對時同時完成：
- 書籍表：填寫「類型」與「位置」。
- 曲目表：校對完的列，將備註的「AI 擷取，待校對」刪除。

## 6. 貼進目錄與資料檢查

1. 將校對完的 CSV 內容貼到目錄的書籍表與曲目表最下方。曲目表只貼到「備註」欄，不要覆蓋自動欄位。
2. 匯出三張表的 CSV，執行資料檢查：

```bash
python3 tools/validate_catalog.py 書籍.csv 曲目.csv 選項.csv
```

3. 修正所有「錯誤」後才能進行下一批。「提醒」可留待標籤階段處理。

## 7. 貼標籤、上架

1. 在書背貼上位置標籤，例如 `A-2-05`。
2. 依編號順序放回書櫃。
3. 在曲目表抽查 3 首曲子，用搜尋頁查詢，確認能依位置找到書。
