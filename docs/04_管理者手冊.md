# 04 管理者手冊

| 項目 | 內容 |
|---|---|
| 對象 | 教室負責人 |
| 文件版本 | v1.0 |

本手冊說明系統的初次建置方式，以及日常維護工作。

## 1. 初次建置

有兩種方式：

| 方式 | 適合 | 做法 |
|---|---|---|
| 自動建置 | 由建檔人員在電腦上執行 | `tools/setup_google_sheet.py` 自動完成 1.1、1.2、1.4 並驗證公式，見《08 API 與金鑰設定》 |
| 手動建置 | 不使用程式 | 依下列 1.1–1.5 操作 |

兩種方式完成後，都要再手動做 1.3（篩選檢視）與 1.5（保護自動欄位）。

### 1.1 匯入目錄範本

1. 登入教室的 Google 帳號，開啟 Google Drive。
2. 建立資料夾「鋼琴教材目錄」，底下再建「PDF 教材」「示範音檔」兩個子資料夾。
3. 將 `system/鋼琴教材目錄.xlsx` 上傳到「鋼琴教材目錄」資料夾。
4. 對檔案按右鍵 →「開啟工具」→「Google 試算表」。
5. 開啟後選「檔案」→「另存為 Google 試算表」。之後都使用這份 Google 試算表版本。

匯入後請確認：

| 檢查項目 | 預期結果 |
|---|---|
| 分頁 | 使用說明、書籍、曲目、選項 |
| 曲目表的「程度」欄 | 點選後出現 1級–8級 下拉選單 |
| 曲目表第 2 列的「書名（自動）」 | 顯示「布爾格繆勒 25 首練習曲 Op. 100」 |
| 曲目表第 2 列的「位置（自動）」 | 顯示「A-2-05」 |

### 1.2 建立搜尋頁

1. 在最左邊新增一個分頁，命名為「搜尋」。
2. A1 輸入 `請輸入關鍵字：`，B1 留白，作為輸入格。
3. A2 到 G2 依序輸入欄位名稱：`曲名`、`作曲家`、`書名`、`頁碼`、`位置`、`程度`、`示範音檔`。
4. 在 A3 貼上以下公式：

```text
=IF($B$1="","",IFERROR(FILTER(CHOOSECOLS(曲目!A2:N,3,4,13,5,14,6,11),ISNUMBER(SEARCH($B$1,曲目!C2:C&" "&曲目!D2:D&" "&曲目!M2:M&" "&曲目!J2:J))),"找不到符合的曲目"))
```

5. 在 B1 輸入 `Burgmüller`，確認 A3 出現範例曲目 La Candeur (Op. 100 No. 1)、頁碼 2、位置 A-2-05。

公式會同時搜尋曲名、作曲家、書名和技巧重點，不分大小寫。

### 1.3 建立篩選檢視

在曲目表選「資料」→「建立篩選檢視」，依下表建立幾個常用檢視：

| 檢視名稱 | 條件 |
|---|---|
| 初級曲目 | 程度為 1級、2級、3級 |
| 中級曲目 | 程度為 4級、5級 |
| 巴洛克 | 時期為 巴洛克 |
| 有示範音檔 | 示範音檔不是空白 |

篩選檢視不會影響其他老師看到的畫面，可以放心使用。

### 1.4 共用設定

1. 右上角「共用」→ 加入 3 位老師的 Google 帳號，權限設為「編輯者」。
2. 「一般存取權」維持「限制」，不要設成「知道連結的任何人」。
3. 請老師們在手機安裝 Google 試算表 App，並將這份目錄加星號，方便找到。

### 1.5 保護自動欄位

1. 在曲目表選取 M、N 兩欄（書名、位置的自動欄位）。
2. 右鍵 →「保護範圍」→ 設定為「只有你可以編輯」。

這樣可以避免老師不小心覆蓋公式。

## 2. 日常維護

### 2.1 新增一本書（約 5 分鐘）

1. 在書籍表最下方新增一列，書籍編號接續最後一個（例如最後是 B0215，新的就是 B0216）。
2. 填入書名、類型、位置；PDF 教材則將檔案放進「PDF 教材」資料夾，貼上連結。
3. 拍下目錄頁，請 AI 工具擷取曲目（見《05 建檔作業流程》第 4 節「少量新增」），對照書本校對後，貼到曲目表。
4. 曲目編號接續最後一個。
5. 在書背貼上位置標籤，放上書櫃。

### 2.2 新增下拉選項

到選項表，在對應欄位的最下方加上新值。曲目表的下拉選單會自動出現新選項。

**不要修改或刪除已在使用的選項**，否則已經填了該值的曲目會變成無效值。如果要改名，請先用「尋找與取代」把曲目表裡的舊值全部換掉。

### 2.3 每月檢查（約 10 分鐘）

1. 匯出備份：分別切到書籍、曲目、選項三張表，選「檔案」→「下載」→「逗號分隔值檔案 (.csv)」，存到電腦或 Drive 的「備份」資料夾，檔名加上日期。
2. 執行資料檢查（需要一台裝有 Python 3.9 以上的電腦，見 2.4）。
3. 有錯誤時，依檢查結果的列號回到試算表修正。

### 2.4 執行資料檢查工具

```bash
python3 tools/validate_catalog.py 書籍.csv 曲目.csv 選項.csv
```

| 結果 | 意義 |
|---|---|
| `錯誤 0 個` | 資料沒有問題 |
| `[錯誤] 曲目 第 15 列…` | 曲目表第 15 列需要修正 |
| `[提醒] …還沒有填程度` | 不影響使用，有空再補 |

工具會檢查：必填欄位、編號格式與重複、曲目對應的書籍是否存在、下拉選項是否有效、頁碼格式、位置格式、同一本書是否重複登錄同一首曲子。

### 2.5 誤刪資料時

選「檔案」→「版本記錄」→「查看版本記錄」，找到誤刪前的版本並還原。

## 3. 常見問題

| 問題 | 原因與處理 |
|---|---|
| 書名（自動）顯示「找不到書籍」 | 書籍編號打錯，或書籍表還沒新增該書 |
| 下拉選單出現紅色警告 | 輸入的值不在選項表裡；改從下拉選單選擇 |
| 搜尋頁顯示「找不到符合的曲目」 | 換個關鍵字，例如只輸入作曲家或曲名的一部分 |
| 搜尋頁公式出現錯誤 | 確認曲目表欄位順序沒有被調整；欄位順序不可變動 |
| 目錄上的位置找不到書 | 書可能被借出或放錯位置；請依書背編號歸位 |
